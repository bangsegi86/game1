# 포탄대결 (Shell Clash)

친구들과 웹 브라우저로 즐기는 턴제 포격 대전 게임. 서버는 내 Windows PC에서, 친구들은 주소만 열면 됩니다.

- 기획·설계서: https://claude.ai/artifact/6Q8s9cAKA13LNwTqZnWiuM
- 아트 시안과 목업: `mockup/` (화면 목업, 탱크·아이템·맵 도감)

## 혼자 해 보기

방을 만든 뒤 **컴퓨터 추가**를 누르면 컴퓨터 플레이어가 들어옵니다(최대 7명). 컴퓨터는 항상 준비 상태라 바로 시작할 수 있어요.

## Windows에서 서버 켜기

1. [Node.js](https://nodejs.org) LTS(22.13 이상, 24 권장)를 설치합니다.
2. 이 저장소를 내려받아 압축을 풉니다.
3. `start-server.bat`을 더블클릭합니다. 처음 한 번은 필요한 파일을 내려받느라 조금 걸립니다.
4. 창에 나오는 주소로 접속합니다.
   - 내 PC: `http://localhost:3000`
   - 같은 공유기(집 와이파이)의 친구: 창에 나온 `http://192.168.x.x:3000`
5. 처음 실행할 때 Windows 방화벽 창이 뜨면 **허용**을 누릅니다.

### 집 밖 친구가 들어오려면 (둘 중 하나)

- **공유기 포트포워딩**: 공유기 설정에서 외부 3000번을 내 PC의 3000번으로 연결하고, 친구에게 `http://내공인IP:3000`을 알려 줍니다.
- **Tailscale(무료 VPN, 더 쉬움)**: 나와 친구 모두 Tailscale을 설치하고 같은 네트워크에 초대한 뒤, 내 PC의 Tailscale 주소 `http://100.x.x.x:3000`으로 접속합니다.

포트를 바꾸려면 `start-server.bat`에서 실행 줄 앞에 `set PORT=4000`을 넣습니다.
로그인은 1시간 동안 아무것도 하지 않으면 풀립니다. 새로고침하거나 잠깐 끊겨도 1분 안에 돌아오면 방(과 게임)에 그대로 남습니다.
계정과 전적은 `server/data/shellclash.db` 파일 하나에 저장됩니다. 백업하려면 이 파일을 복사해 두세요.

## 개발

```
cd server
npm install
npm start      # http://localhost:3000
npm test       # 서버 테스트
```

- `server/src` 서버(Express + Socket.IO + 내장 SQLite). `game.js`가 한 판의 진행(턴·타이머·판정)을 맡는다
- `shared/sim` 전투 시뮬레이션(지형 격자, 물리, 필살기, 이벤트). 서버가 판정하고 화면도 같은 코드로 재생한다
- `client/` 웹 화면. `js/render.js`가 전투를 그리고 `js/battle.js`가 조작을 보낸다
- `mockup/art.js` 탱크·포탄·아이템 그림 (실제 게임도 이 파일을 쓴다), `mockup/*.html` 시안과 도감
